PerformanceVault (CW2 Demo UI)

Local demo UI for CW2: Azure Function (SAS) + Blob upload + Logic Apps CRUD + Cosmos metadata.

1) Request SAS + Upload media to Blob

Flow: Request SAS → Upload file using returned uploadUrl.

Blob container: media-raw 
---
2) Create metadata (Cosmos DB via Logic App)

Uses containerName and blobName returned from SAS step.

Cosmos DB: performanceVault / media 
---
3) Read / Update / Delete metadata (Logic Apps)

Delete performs: delete blob (if exists) → delete Cosmos doc → returns result.

Query scope: {teamIdQuery} 
---
